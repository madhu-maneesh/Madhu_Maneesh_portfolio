# Madhu Maneesh — Portfolio

Cinematic, high-performance developer portfolio built with Next.js 16, Tailwind CSS v4, Framer Motion, and TypeScript. Featuring a stylized 3D developer workstation, interactive particle network, and production-grade engineering showcase.

## Visual Identity & Theme

- **Primary Theme:** Graphite / Dark Obsidian (`#090B10`, `#11151C`, `#171D26`)
- **Accents:** Software Blue (`#4B9BFF`) & Subtle Lime (`#C5FF55`)
- **Monogram:** MM (Madhu Maneesh)
- **Workstation:** Stylized 3D developer workstation with Navy Blue T-shirt bearing light-blue MM monogram, laptop code editor, and interactive 3D perspective tilt.

## Tech Stack

- **Framework:** Next.js 16 (App Router) + TypeScript
- **Styling:** Tailwind CSS v4
- **Motion:** Framer Motion (respects `prefers-reduced-motion`)
- **Contact API:** Resend + Zod validation + sliding-window rate limit
- **Icons:** Lucide React + React Icons

## Features & Sections

1. **Hero** — 3D interactive developer workstation, live IST clock, animated terminal quote snippet
2. **About** — Educational background, engineering philosophy, technical focus areas
3. **Experience** — Software Engineer Intern at AIRA HR (video pipeline, file watchers, rsync, FFmpeg)
4. **Projects** — VectorVault (Java RAG), R-Scorer (ATS Resume Analysis), Shortify, TripNest, AgroBench, Smart Notify, TopTech Telegram Bot
5. **Skills** — Complete technical inventory organized by clean categories without fake percentages
6. **Contact** — Direct email, GitHub, LinkedIn, and validated contact message form

## Getting Started

```bash
npm install
npm run dev        # http://localhost:3000
```

## Build & Quality Checks

```bash
npm run build      # production build
npm run typecheck  # tsc --noEmit
npm run lint       # ESLint
npm run test       # Vitest tests
```

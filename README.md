## About this site

The portfolio has a hero section with a 3D developer workstation, a live IST clock and a terminal animation, followed by About, Experience, Projects, Skills and Contact sections. The contact form has validation, and the skills section has no fake percentage bars.

Built with Next.js 16 (App Router), TypeScript, Tailwind CSS v4 and Framer Motion. The theme is dark graphite, with blue and lime accents.

## Run it locally

```bash
git clone https://github.com/madhu-maneesh/Madhu_Maneesh_portfolio.git
cd Madhu_Maneesh_portfolio
npm install
npm run dev
```

Then open http://localhost:3000

Other commands:

```bash
npm run build
npm run typecheck
npm run lint
npm run test
```
